# Lista de proxies — copie este arquivo para "proxies.txt" e preencha.
# Um proxy por linha. Linhas em branco ou com "#" são ignoradas.
#
# Formatos aceitos:
#   http://usuario:senha@host:porta
#   https://usuario:senha@host:porta
#   host:porta            (assume http://)
#
# Importante:
# - O arquivo "proxies.txt" NÃO deve ser versionado (já está no .gitignore),
#   pois contém credenciais.
# - A API está atrás de Cloudflare: proxies de datacenter/listas grátis
#   costumam ser bloqueados. Prefira proxies residenciais/móveis.
# - Teste antes de usar:  python proxies.py --testar
#
# Exemplos (substitua pelos seus):
# http://usuario:senha@198.51.100.10:8000
